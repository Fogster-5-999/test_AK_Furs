# Проверка и допущения

Банковские строки читаются в CP1251; строки с назначением вида «счёт №...», «по счёту №...» не связываются с заказом без отдельного номера заказа. Для Q4 в output/q4_chat_audit.csv записаны первые найденные менеджерские приглашение и озвучивание цены с временными метками и исходным текстом. Проверяйте эти реплики для пограничных формулировок: эвристический поиск по тексту не заменяет ручную проверку. Ответ для C0010 использует исторический диапазон прайса на дату чата (04.09.2025); CRM-заказ, созданный позднее переписки, в сообщение не включается. Пустые и некорректные обязательные числовые поля приводят к ошибке вместо подстановки нуля. Исходные файлы не изменяются.
